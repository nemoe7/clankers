# userscripts Agent Rules

- Record newly discovered userscript bugs, DOM selector hazards, and dead ends in `userscripts/AGENTS.md` whenever a fix lands so other agents NEVER repeat them.
- Bump `@version` and the version suffix in `@name` one step above `main` per PR when editing `userscripts/*.user.js`.
- Add controls in `openSettingsModal()` (`#clankers-settings-modal`) for every new feature, toggle, and configurable parameter.
- Keep the 26 Tampermonkey menu command labels (`GM_registerMenuCommand`) unchanged unless explicitly instructed to change them.
- Make every `MutationObserver` callback strictly idempotent: compare current `textContent`, attributes, and style value/priority before mutating the DOM, observe `document.body` instead of `<head><title>` for `page-tab-title`, and guard `syncTitle` logs on `currentTitleEmoji(doc.title) !== titleEmoji` (plus preserve `proxyBoardCache` against unseeded `revision === 0` empty pulls) so prefix/symbol updates NEVER trigger repeated emoji churn.
- Exclude transcript children (`[role="log"]`, `[data-perf-target="transcript"]`, `.max-w-3xl`) when selecting outer layout or composer wrappers (`div.flex.min-h-0.flex-1.flex-col > div.shrink-0`).
- Detect open preview drawers by preview-specific controls (`button[aria-label="Close preview"]`, `iframe[title^="App preview"]`), NEVER by `button[aria-label="Collapse workspace sidebar"]` alone (`256px` `Workspace card views` sidebar keeps that button when the preview is closed).
- Lock width on both the outer (`div.absolute.bottom-0.end-0.top-0.z-10.overflow-clip`) and inner (`> div`) preview drawer containers.
- NEVER fall back to timestamped downloads when a quiet state save fails; show `#clankers-state-panel` specifying the error and offering `Choose file`.
- Keep `storeKey` in `fetchStateFile` aligned with `stateScope(document)` instead of overwriting it with `body.scope.branch`, fall back to `lastScope` and `serverStoreKey` handles, prioritize in-memory `selected` when `selectedKey` matches any candidate scope, and make `chooseStateFile` clear stale receipts and force-save immediately.
- In `chipRepo`, NEVER return a lone `SESSION_BRANCH_RE` (`arena/<hash>-<repo>`) chip as the repository slug when `hits === 1`; return `repo` only so `detectRepo` falls through to `titleRepo`.
- Cache `lastPreviewBase` and `clankers-arena-preview-base-<sid>` so `Choose file`, `Force save`, and `syncPreviewBoardHook` reach `:8000` with closed drawers.
- Run periodic `syncPreviewBoardHook` with `state-download` active, watch `BOARD_KEY` via `GM_addValueChangeListener`, and isolate unallowlisted sessions in `mergePreviewBoard`.
- Gate `GM_addValueChangeListener(BOARD_KEY)` on allowlisted tab sessions and `boardMaterialSignature` changes, pass `{ passive: true }` on listener and timer syncs so `syncPreviewBoard` NEVER invents synthetic `updated_at` stamps, and skip `GM_setValue(BOARD_KEY)` in `writeGlobalBoard` when material board state has not changed within `15s` so cross-tab listeners NEVER enter a `GM_setValue` ping-pong storm.
- Apply `report_ops` to `worker_reports` and `localSessionReportsBySid` while keeping decisions ahead of `entry-ack` ops. Exclude peer `worker_reports` from `boardHasWaitingReportFor` and strip survey answers on unopted rows.
- Strip board `entries`, `worker_tasks`, peer `worker_reports`, `task_ops`, `report_ops`, and `wakes` from unopted sessions in `scopeBoardForTarget`, drop unopted `disconnected` rows past `BOARD_SESSION_TTL_SECONDS` in `normalizeBoard`, hide unlinked cross-repo rows when `multi_repo` is `false` in `scopeBoardForTarget`, ignore unopted session `heartbeat` messages, pass `previewUiSessionId` instead of target `event.data.action.session_id` to post-action `syncPreviewBoard`, and honor global and main-session `removed_sessions` revocations over stale peer `allowed_sessions` in `mergePreviewBoard`.
- When `clankers-arena-proxy-host` and `clankers-arena-proxy-master` are configured, keep board state in `proxyBoardCache` and run pure transport in `syncPreviewBoard` (pull member `GET /api/board`, post to `/v1/board` for egress consolidation, pull consolidated `/v1/board?since=<revision>` plus `/v1/board/files`, and post consolidated state at most once to `/api/board` without client-side `set-main`/`allow` healing chains or `GM_setValue(BOARD_KEY)`).
- Omit live `body.digest` from `mismatchOfferId` so acknowledging a backup upload note does not re-upload the same local `.ndjson` file on every subsequent server digest change.
- NEVER schedule top-level `setTimeout`, `setInterval`, or `jitteredTimer` calls outside `runFeature` modules (`userscripts.test.cjs` rejects top-level `setTimeout` and checks `active.intervals === intervalsFor(stored)`), and piggyback periodic allowlisted board syncs on existing feature timers (`state-download` and `page-tab-title`).
- Initialize `BOARD_KEY`, `onPreviewMessage`, `notifyPreviewReady`, and `syncPreviewBoard` above `runFeature` calls and keep `syncPreviewBoard` independent of `stateBusy`.
- In `mergePreviewBoard`, merge `seen_at`, `acknowledged_at`, `ack_type`, `ack_text`, `ack_sender`, `ack_edited_at`, `replies`, and `task_id` onto existing board entry IDs instead of skipping duplicate IDs, scope `main_session_id` per target session/repo via `scopeBoardForTarget` so unopted or cross-repo sessions never inherit another repo's `main_session_id` or `worker` role, and keep `main` role assignment independent per repository so only each repo's `main` session posts preview URLs to the preview proxy.
- Send `X-Clankers-Userscript-Version` on preview `:8000` HTTP requests (`requestJson`, `sendSteeringInterrupt`, and `stateJson`) and `version` in `clankers:userscript-ready`, keeping `USERSCRIPT_VERSION` synced with `@version`, while omitting custom headers on external `arena-preview-proxy` `/pwa/recent` posts (`sendRecentPreview` and `removeRecentPreview`), falling back `discoverPreviews` `uiRepo` to `stateScope(doc).repo` and `steeringBase` to `lastPreviewBase`, and recording `previewUiSessionId` before `syncPreviewProxyHook()` in `clankers:preview-ready`.
- NEVER put en-dashes (`\u2013`) or em-dashes (`\u2014`) in `userscripts/*.user.js` or `userscripts/README.md`.
- Run both `node --test tests/userscripts/userscripts.test.cjs` and `node --test tests/userscripts/userscripts.checks.cjs` via `arena-preview run start` before pushing `userscripts/` changes.
