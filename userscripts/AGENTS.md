# userscripts Agent Rules

- Record newly discovered userscript bugs, DOM selector hazards, and dead ends in `userscripts/AGENTS.md` whenever a fix lands so other agents NEVER repeat them.
- Bump `@version` and the version suffix in `@name` one step above `main` per PR when editing `userscripts/*.user.js`.
- Add controls in `openSettingsModal()` (`#clankers-settings-modal`) for every new feature, toggle, and configurable parameter.
- Keep the 25 Tampermonkey menu command labels (`GM_registerMenuCommand`) unchanged unless explicitly instructed to change them.
- Make every `MutationObserver` callback strictly idempotent: compare current `textContent`, attributes, and style value/priority before mutating the DOM, observe `document.body` instead of `<head><title>` for `page-tab-title`, and guard `syncTitle` logs on `currentTitleEmoji(doc.title) !== titleEmoji` (plus preserve `proxyBoardCache` against unseeded `revision === 0` empty pulls) so prefix/symbol updates NEVER trigger repeated emoji churn.
- Exclude transcript children (`[role="log"]`, `[data-perf-target="transcript"]`, `.max-w-3xl`) when selecting outer layout or composer wrappers (`div.flex.min-h-0.flex-1.flex-col > div.shrink-0`).
- Detect open preview drawers by preview-specific controls (`button[aria-label="Close preview"]`, `iframe[title^="App preview"]`), NEVER by `button[aria-label="Collapse workspace sidebar"]` alone (`256px` `Workspace card views` sidebar keeps that button when the preview is closed).
- Lock width on both the outer (`div.absolute.bottom-0.end-0.top-0.z-10.overflow-clip`) and inner (`> div`) preview drawer containers.
- Keep `/v1/state` on `arena-egress-proxy` as the sole userscript state backend with zero `showSaveFilePicker`, IndexedDB file handles, or browser downloads. Render `#clankers-state-panel` only on failed `/v1/state` requests (`Retry save`) or missing proxy configuration on manual force saves (`Settings` via `openSettingsModalHook`).
- Store dynamic cursor, state, and file-hydration maps in `Map`/`Set` (never plain `{}` bracket lookups or in-place `cached.rev = ...` mutations) so CodeQL `js/prototype-polluting-assignment` never triggers on message or HTTP keys.
- Use `WeakMap` for DOM-element state maps (`spacerStyles` and `editorStates`), cap per-origin/per-scope state and board cursor caches (`previewAutosavePullByBase`, `proxyStateCacheByScope`, `hydratedBoardFilesByBranch`) with bounded eviction while omitting `core`/`text` from `pendingKey` and cached `fullSnap.text`, and coalesce `hide-composer` and `tab-title` `MutationObserver` callbacks behind `requestAnimationFrame`.
- Sync `/api/userscript-autosave` and `/v1/state` via `computeStateDiff` and `applyStateDiff` cursors. Fall back to full snapshots on reset or `409`, and fetch `?include_text=1` for mismatch backup offers.
- In `chipRepo`, NEVER return a lone `SESSION_BRANCH_RE` (`arena/<hash>-<repo>`) chip as the repository slug when `hits === 1`; return `repo` only so `detectRepo` falls through to `titleRepo`.
- Cache `lastPreviewBase` and `clankers-arena-preview-base-<branch>` so `Force save` and `syncPreviewBoardHook` reach `:8000` with closed drawers.
- Keep `/v1/board` as the sole board backend in `proxyBoardCache` with zero caps or `BOARD_KEY`. Key board sessions, entries, allowlists, wakes, `worker_ids`, `worker_tasks`, and `worker_reports` by Git `branch`, keeping `main_session_id` for `SKILL.md` compatibility, passing `branch` and `repo` on `/v1/board` pulls, skipping `entry.acknowledged_at` in `hydrateBoardFilesForTarget`, probing `:8000` `/api/board` before `pushOnly` `/v1/board/files` downloads, and encoding `/` as `%2F` only under `board-files/`. Sync `/api/board` and `/v1/board` via `computeBoardDiff` and `applyBoardDiff` cursors with `409` fallback.
- Apply `report_ops` to `worker_reports` and `localSessionReportsByBranch` while keeping decisions ahead of `entry-ack` ops. Exclude peer `worker_reports` from `boardHasWaitingReportFor` and strip survey answers on unopted rows.
- Strip board `entries`, `worker_tasks`, peer `worker_reports`, `task_ops`, `report_ops`, and `wakes` from unopted sessions in `scopeBoardForTarget`, drop unopted `disconnected` rows past `BOARD_SESSION_TTL_SECONDS` in `normalizeBoard`, hide unlinked cross-repo rows when `multi_repo` is `false` in `scopeBoardForTarget`, pass `previewUiBranch` instead of target `event.data.action.branch` to post-action `syncPreviewBoard`, scope `main_session_id` per target branch/repo via `scopeBoardForTarget` so unopted or cross-repo sessions never inherit another repo's `main_session_id` or `worker` role, and keep `main` role assignment independent per repository so only each repo's `main` session posts preview URLs to the preview proxy.
- Omit live `body.digest` from `mismatchOfferId` so acknowledging a backup upload note does not re-upload the same local `.ndjson` file on every subsequent server digest change.
- NEVER schedule top-level `setTimeout`, `setInterval`, or `jitteredTimer` calls outside `runFeature` modules (`userscripts.test.cjs` rejects top-level `setTimeout` and checks `active.intervals === intervalsFor(stored)`), and piggyback periodic allowlisted board syncs on existing feature timers (`state-download` and `page-tab-title`).
- Initialize `onPreviewMessage`, `notifyPreviewReady`, and `syncPreviewBoard` above `runFeature` calls and keep `syncPreviewBoard` independent of `stateBusy`.
- Freeze `USERSCRIPT_BOOT_VERSION` at page-load boot so `userscriptVersion()` never mutates if Tampermonkey updates in the background without refreshing the tab, and forward live `/v1/key` and `/v1/board` `egress_version` values to `:8000` `/api/key` and `/api/board`. Send `X-Clankers-Userscript-Version` on preview `:8000` HTTP requests (`requestJson`, `sendSteeringInterrupt`, and `stateJson`) and `version` in `clankers:userscript-ready`, keeping `USERSCRIPT_VERSION` synced with `@version`, while omitting custom headers on external `arena-preview-proxy` `/pwa/recent` posts (`sendRecentPreview` and `removeRecentPreview`), falling back `discoverPreviews` `uiRepo` to `stateScope(doc).repo` and `steeringBase` to `lastPreviewBase`, and recording `previewUiBranch` before `syncPreviewProxyHook()` in `clankers:preview-ready`.
- NEVER put en-dashes (`\u2013`) or em-dashes (`\u2014`) in `userscripts/*.user.js` or `userscripts/README.md`.
- Keep `titleStep` allowlisted `:8000` board sync cadence on `BOARD_PROXY_POLL_MS` with an in-flight guard, and trigger composer `"wake up"` once per unseen `wakes[branch]` token only after `:8000` sync confirms the session is idle (`!polling` and no stop button).
- Seed `:8000` `/api/board` once per preview origin on first connect via read-only `/v1/board` pulls. Never send `POST /v1/board` `sync` or `disconnect-session` for unopted branches before opt-in.
- Strip leading `@` prefixes in `resolveBoardTarget` and resolve `entry.to` aliases during `normalizeBoard` so `-t @main` or `-t @beta` posts hydrate and deliver to the target branch.
- Run both `node --test tests/userscripts/userscripts.test.cjs` and `node --test tests/userscripts/userscripts.checks.cjs` via `arena-preview run start` before pushing `userscripts/` changes.
