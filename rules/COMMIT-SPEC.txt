Conventional Commits reference, at <https://www.conventionalcommits.org/en/v1.0.0/>: follow the project's commit convention when it states one; otherwise `<type>[optional scope]: <description>`, imperative, lowercase after ":", no period, <=72 chars, with `!` before the colon for a breaking change, NEVER a body; types feat fix refactor perf style docs test build chore, where only `feat` and `fix` are mandated and the rest come from the Angular convention through `@commitlint/config-conventional`, so prefer the types the project's history uses; reuse prior scopes.
